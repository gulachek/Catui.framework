# Dependency Licenses

This directory should exist in the
`Catui.framework/Resources/DEPENDENCY-LICENSES` directory to
provide appropriate license file's for this framework's
dependencies.

If a license file does not exist in the framework bundle for any
dependency, please file a bug report. You can find the licenses
associated with each individual dependency as listed below at
each respective repository URL.

## Dependencies

| Dependency   | Repository URL                            | Usage Description                             |
| ------------ | ----------------------------------------- | --------------------------------------------- |
| `cJSON`      | <https://github.com/DaveGamble/cJSON/>    | JSON serialization                            |
| `msgstream`  | <https://github.com/gulachek/msgstream/>  | msgstream serialization                       |
| `unixsocket` | <https://github.com/gulachek/unixsocket/> | Basic unix domain socket operations           |
| `catui`      | <https://github.com/gulachek/catui/>      | Underlying implementation of core catui logic |
